# R286 Preregistration — US500 Three-Session Overextension Reversal

**Candidate ID:** `R286_US500_3SESSION_OVEREXTENSION_FADE`  
**Status:** locked before calculating returns/PnL.  
**Date:** 2026-10-17.

## Hypothesis and parent comparison

A multi-session directional extension may overshoot short-term fair value, producing an intraday reversal the following regular session. This is a fixed, daily-horizon hypothesis. It is distinct from R260's single large H1-candle shock fade and R283's cash-open gap fade; it uses neither a cash-open gap trigger nor an opening-range pattern.

The matched parent is an ablation on exactly the same signal dates and entry/exit timestamps, but follows the three-session move instead of fading it. It is a diagnostic baseline only; a positive result for it does not automatically promote that direction.

Require exact unique timestamps, valid positive OHLC, internally consistent highs/lows, and no repeated-flat candidate (O=H=L=C=previous raw row close). No missing bars are synthesized. Completely flat placeholder-only dates are not considered active sessions; a date with any intraday range is a calendar-session candidate, even if the session fails quality checks.
- A valid signal requires a current active session and the three immediately previous active session dates to have valid RTH data. If any date in that four-session window is incomplete or has a repeated-flat candidate, skip that signal date rather than reaching farther back for substitute sessions.
- A trade generated by signal date t enters only on the immediately next observed active session t+1 if that entry session is quality-valid. If t+1 is invalid, skip the trade; never delay and substitute a later session.

## Frozen signal, entry and exit

1. Let `C_t` be the 15:55 ET M5 bar close on valid active session t.
2. Three-session move is `C_t / C_(t-3) - 1`, using three consecutive valid active sessions. Signal is known only after session t closes.
3. Fit one absolute-move threshold: the 80th percentile of absolute three-session moves whose current signal date is in discovery 2017–2020. Freeze that threshold for all later dates. There is no parameter grid.
4. If the three-session move is above the positive threshold, candidate enters SHORT; if below its negative, candidate enters LONG; otherwise no trade. Matched parent takes the same event direction as the three-session move. At most one position per session and no pyramiding.
5. Entry on the following active session at the 09:40 ET bar open, ten minutes after the 09:30 bar begins to model the user's close-confirmation/phone workflow. Exit at the same session's 15:55 ET bar close. No overnight exposure, stop, target or size compounding in this signal-screen stage.
6. Trade return is direction-signed `(exit / entry - 1) × 10,000` basis points before costs. Deduct modeled 1, 2 or 4 bp round-trip notional costs. Primary screen cost is 2 bp. These are cost stresses, not observed spread, commission or slippage; source is BID-only.
